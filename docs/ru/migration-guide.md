# Руководство по миграции

## 0.2.x → 0.2.7 (resize-handle)

**Ломающее изменение** (только CSS):
`min-height`/`max-height` перенесены с `.dsk-wysiwyg__content` на
корневой `.dsk-wysiwyg`. Если хост-проект задаёт размеры через
внутренний селектор контента, перейдите на корневой или используйте
новые CSS-переменные (`--dsk-wysiwyg-min-height`,
`--dsk-wysiwyg-max-height`), которые сохраняют прежний API.

## 0.2.0 → патч-серия 0.2.x (B1-B7, F1-F4)

Без ломающих изменений — исправления ошибок и новые возможности тулбара
(режим исходного кода, beautify/minify, оверлей подсветки синтаксиса).

## 0.1.x → 0.2.0

**Бандл**: ~7 KB → ~12 KB gz (добавлены markdown-шорткаты, slash-меню,
таблицы, подсветка синтаксиса). Новых peer-зависимостей нет.

**Whitelist санитайзера** расширен: `table`/`thead`/`tbody`/`tr`/`th`/`td`,
атрибут `class` на `code`/`span` с префиксами `language-` и `dsk-tok-`.

**Дополнения публичного API**:
- `htmlToMarkdown(html)` — конвертер HTML в Markdown
- `highlight(code, language)` — подсветка синтаксиса (возвращает HTML)
- `DskWysiwygSlashMenu` + тип `SlashCommand` — для собственных
  расширений slash-команд

## 0.0.x → 0.1.0 (первая стабильная)

Предстабильные релизы. Всё до 0.1.0 может содержать ломающие изменения.
